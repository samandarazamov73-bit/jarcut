# CapCut-Lite — Лёгкий видеоредактор с озвучкой

Локальный видеоредактор для наложения TTS-озвучки на видео.
Генерирует несколько вариантов голоса через Gemini API, позволяет
выбрать лучший и синхронизировать с таймлайном видео.

## Возможности

- Загрузка видео с компьютера
- Временная шкала (timeline) с масштабированием
- Маркеры-реплики: перетаскивание, изменение длительности
- Генерация 3 вариантов озвучки через Gemini TTS
- Прослушивание и выбор лучшего варианта
- Ручная загрузка аудио к маркеру
- Синхронизированное воспроизведение (видео + все аудио-маркеры)
- Сохранение/загрузка проектов (JSON)
- Экспорт: склейка видео + аудио через ffmpeg

## Быстрый старт

### 1. Установка

```bash
# Клонируем/скачиваем проект
cd capcut-lite

# Устанавливаем зависимости Python
pip install -r requirements.txt

# Копируем файл настроек и вставляем API-ключ
cp .env.example .env
# Отредактируйте .env — вставьте свой GEMINI_API_KEY
```

### 2. Получение API-ключа Gemini

1. Откройте https://aistudio.google.com/apikey
2. Создайте новый ключ (бесплатно)
3. Вставьте ключ в файл `.env`

### 3. Запуск

```bash
python server.py
```

Или через uvicorn (с авто-перезагрузкой при изменениях):

```bash
uvicorn server:app --reload --port 8000
```

Откройте в браузере: **http://localhost:8000**

### 4. Использование

1. **Загрузить видео** — перетащите файл или нажмите кнопку
2. **Добавить маркер** — кнопка "＋" или установите позицию в видео
3. **Написать текст** — в правой панели введите реплику
4. **Сгенерировать озвучку** — нажмите "Сгенерировать" → получите 3 варианта
5. **Выбрать вариант** — прослушайте каждый, нажмите "Выбрать"
6. **Воспроизвести** — нажмите Play (или пробел) — аудио синхронизировано с видео
7. **Экспорт** — нажмите "Экспорт" для финальной склейки через ffmpeg

## Требования

- Python 3.9+
- ffmpeg (для экспорта) — `sudo apt install ffmpeg` или скачать с ffmpeg.org
- Современный браузер (Chrome/Firefox/Edge)
- API-ключ Google Gemini

## Структура проекта

```
capcut-lite/
├── server.py           # Сервер (FastAPI)
├── requirements.txt    # Python-зависимости
├── .env.example        # Шаблон настроек
├── .env                # (ваш ключ, не в git)
├── projects/           # Сохранённые проекты
├── exports/            # Экспортированные видео
├── uploads/            # Загруженные файлы
└── static/
    ├── index.html      # Главная страница
    ├── css/style.css   # Стили
    └── js/
        ├── app.js      # Главный модуль
        ├── timeline.js # Таймлайн + drag & drop
        ├── tts.js      # TTS-генерация
        └── audio.js    # Аудио-движок (Web Audio API)
```

## Примечания

- Это **локальный** инструмент — никакой авторизации, работает только на вашем компьютере
- API-ключ хранится в `.env` на сервере и никогда не попадает в браузер
- Проекты сохраняются как JSON-файлы в папке `projects/`
- Для экспорта нужен установленный ffmpeg
